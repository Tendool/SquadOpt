        Inside the model

        The pipeline in squad_engine.py, with numbers from the latest run.

        1 · AHP player utility

        Pairwise judgments, then the principal eigenvector. Utility only breaks ties between squads that are equally strong.

        2 · Integrated ILP

        Selects the squad (x), the starting XI (y) and one designated backup per slot type (z) in a single model.

        max (1−p)·QXI + p·D
        s.t. Σx = N, Σc·x ≤ B, slots filled exactly, y ≤ x, z ≤ x − Σy, group minimums, ≤ 3 GK

        3 · Evaluation

        Monte-Carlo: each player is missing with probability p. The best XI is re-picked from those available (Hungarian algorithm).

        Constraint checks (independent re-computation)

          Verified

          The test suite (pytest) checks on every change that pruning never changes the optimum, that HiGHS and CBC agree, and that every solution passes these checks.
