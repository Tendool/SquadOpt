        Model

        How squad_engine.py chose this squad, with the numbers from the latest run.

          Player utility (AHP)

          Pairwise judgments give the weights. Utility only breaks ties between squads that are equally strong.

          Integer program

          One model picks the squad (x), the starting XI (y) and a backup for every position (z).

          maximise (1 − p)·QXI + p·DΣx = N · Σc·x ≤ B · every slot filled once · y ≤ x · one backup per position, Σtz ≤ x − Σy · line minimums · at most 3 GK · left and right are separate positions

          Evaluation

          Each player misses a match with probability p; the best XI is re-picked from whoever is available, 200 times.

          Constraint checks

          Recomputed independently from the returned squad.

            Verified

            The test suite checks on every change that pruning never changes the optimum, that HiGHS and CBC agree, that every starter is scored with that position's rating, and that every solution passes these checks.
