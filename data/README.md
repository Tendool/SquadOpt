# Dataset

`FC26_20250921.csv`: FC 26 player data, 18,405 players × 110 columns. The app reads it from here by default; the
`FC26_CSV` environment variable can point at another copy.

Source: "FC 26 (FIFA 26) Player Data" by rovnez, Kaggle,
https://www.kaggle.com/datasets/rovnez/fc-26-fifa-26-player-data. The data was scraped from sofifa.com.
